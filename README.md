# Hi, I'm Wang Yan

I'm an engineer in Hangzhou, building tools that help people
work better with AI agents.

I'm currently building **Wombat**, an environment manager
for AI agents.

Wombat aims to bring agent configuration, rules, skills,
MCP connections, usage, and sessions into one place.
The goal is to make agent environments easier to understand,
maintain, and improve.

Development starts with Codex and coding workflows,
with research, writing, office work, and automation
as future directions.
